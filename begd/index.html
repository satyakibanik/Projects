Sources & how to read this dashboard

Overview, power plants, regions, imports, substations, operations, forecast and report comparisons use the selected Power Grid Bangladesh PLC / NLDC daily workbook. The report date selector lists reports using the dashboard's supported workbook layout (31 January 2025 onward). Optional Yesterday’s data and Tomorrow’s data controls load adjacent operating-day workbooks for comparison. Real time is a separate view of ERP rows dated today in Bangladesh time from the demand/supply/load shedding, generation, and India import pages. Only ERP pages with rows for today are displayed; pages without matching rows are omitted. Real time refreshes every three minutes. Highest generation day reads the date shown on Power Grid's maximum-generation page, then loads that operating day's workbook. The workbook operating date can differ from its publication date. The local server refreshes the date list every 30 minutes. Older reports use an earlier workbook layout and are not included in the selector.

All operating times use Bangladesh time (Asia/Dhaka). Generation totals include imports. Power is shown in MW; daily energy is shown in MWh or GWh. Daily energy uses published workbook totals, not sums of chart readings. Generation-side demand, substation-side demand, and reported load shedding are distinct measures. Regional figures are evening-peak snapshots, not full-day demand. Zero output alone does not establish an outage.

Workbook references: P1 (summary, fuel mix, regions, shutdowns and event log), P2 (plant details), GenLog (24-hour unit output and import readings), P3 (substation load), P4 (demand and generation), EWIC (east–west flows), Voltage (substation voltage), and Forecast (day and evening generation availability). Forecast availability remains available in the Forecast tab; the demand and generation plot uses P4 actuals, L-Curve East/West generation, and dotted demand forecast from the previous day’s Forecast Scenario. Plant comparisons include yesterday, tomorrow, and highest-generation reports when selected above. Import route labels follow the workbook. Live sources: demand / supply / load shedding, generation by source, and India imports.
